O Folium é uma plataforma digital de publicação e curadoria comunitária de ensaios de conhecimento. O serviço é oferecido na modalidade gratuita com funcionalidades premium opcionais ("Folium Plus"). O Folium reserva-se o direito de alterar, suspender ou descontinuar qualquer funcionalidade a qualquer momento, com aviso prévio sempre que razoável.

- É permitida uma (1) conta por pessoa. Contas múltiplas, contas de automação não autorizadas ou contas criadas para manipulação de avaliações serão suspensas sem aviso prévio.
- Você é responsável por todas as atividades realizadas sob sua conta.

### 4.1 Titularidade

- Avaliações negativas não são exibidas publicamente, mas influenciam os algoritmos de ranking internos.

O Folium não se responsabiliza por decisões tomadas com base em conteúdos publicados por usuários.

# POLÍTICA DE PRIVACIDADE

*Em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018)*

## 1. Controlador dos Dados
Os dados pessoais coletados pelo Folium são controlados por [Nome do Fundador / Razão Social], com contato disponível em: **privacy@folium.app**.

## 2. Dados Coletados e Finalidade

### 2.1 Dados fornecidos pelo Google OAuth
Ao autenticar com Google, coletamos exclusivamente:

| Dado | Finalidade |
|------|-----------|
| Nome e sobrenome | Exibição no perfil público e nos ensaios publicados |
| Endereço de email | Identificação única da conta, comunicados de serviço, notificações de conta |
| Foto de perfil (avatar) | Exibição visual no perfil e nos cards de ensaios |
| ID único do Google | Vinculação da conta, prevenção de duplicatas, segurança |

**Importante**: O Folium solicita ao Google apenas as permissões listadas acima. **Não acessamos** sua agenda, Drive, Gmail, contatos, histórico de navegação, localização ou qualquer outro serviço Google.

### 2.2 Dados gerados pelo uso da plataforma
- Ensaios publicados (conteúdo, título, tópico, data)
- Avaliações dadas (frascos positivos e negativos — armazenados para cálculo de ranking)
- Tópicos seguidos
- Logs de acesso (IP, user-agent, timestamp — retidos por 30 dias)
- Preferências de interface (tema claro/escuro — armazenado localmente no dispositivo)

### 2.3 Dados de pagamento (apenas assinantes Plus)
Dados de pagamento são processados integralmente pelo Stripe ou Mercado Pago. O Folium **não armazena** números de cartão, dados bancários ou informações financeiras. Recebemos apenas a confirmação do pagamento.

## 3. Base Legal para Tratamento
- **Execução de contrato**: dados necessários para fornecer o serviço (Art. 7º, V, LGPD)
- **Legítimo interesse**: logs de segurança, prevenção de fraude (Art. 7º, IX, LGPD)
- **Consentimento**: comunicações de marketing (Art. 7º, I, LGPD) — você pode revogar a qualquer momento

## 4. Compartilhamento de Dados
**Não vendemos seus dados pessoais.** Compartilhamos apenas com:

| Parceiro | Dados | Finalidade |
|----------|-------|-----------|
| Supabase (EUA/UE) | Todos os dados da conta | Armazenamento e infraestrutura |
| Vercel (EUA) | Logs de acesso | Hospedagem e performance |
| Stripe / Mercado Pago | Email, nome | Processamento de pagamento (apenas assinantes) |
| Google | Email, ID | Autenticação OAuth |
| Autoridades legais | Conforme exigido | Cumprimento de obrigação legal (Art. 7º, II, LGPD) |

Todos os parceiros possuem políticas de privacidade próprias e cumprem com regulamentações de proteção de dados aplicáveis.

## 5. Seus Direitos (Art. 18, LGPD)
Você tem direito a:

| Direito | Como exercer |
|---------|-------------|
| **Acesso**: receber cópia dos seus dados | Enviar email para privacy@folium.app |
| **Correção**: corrigir dados inexatos | Editar diretamente em Configurações → Perfil |
| **Exclusão**: apagar seus dados pessoais | Configurações → "Excluir minha conta" |
| **Portabilidade**: exportar seus ensaios | Configurações → "Exportar meus dados" (JSON/MD) |
| **Revogação de consentimento**: parar de receber emails de marketing | Link de descadastro em qualquer email enviado |
| **Informação sobre compartilhamento**: saber com quem seus dados são compartilhados | Esta Política de Privacidade |

### Exclusão de Conta
Ao solicitar a exclusão:
- **Dados pessoais** (email, nome, avatar, ID Google): removidos em até 30 dias
- **Ensaios publicados**: anonimizados (autor substituído por "[usuário removido]") para preservar a integridade do conhecimento comunitário
- **Avaliações dadas**: removidas completamente
- **Logs de acesso**: deletados conforme prazo de retenção (30 dias)

## 7. Segurança dos Dados
- Dados armazenados com criptografia em repouso (Supabase)
- Comunicação via HTTPS/TLS obrigatório
- Autenticação via OAuth (sem senha armazenada)
- Acesso interno restrito via MFA (autenticação em dois fatores)
- Logs de acesso para detecção de uso indevido

## 8. Retenção de Dados
| Dado | Retenção |
|------|---------|
| Dados de conta | Até exclusão da conta |
| Ensaios publicados | Permanente (anonimizados após exclusão de conta) |
| Logs de acesso | 30 dias |
| Dados de pagamento | Conforme exigência legal fiscal (5 anos) |

Seus dados podem ser processados em servidores nos EUA (Vercel, Supabase, Stripe). Essas transferências ocorrem com parceiros que mantêm políticas de proteção compatíveis com a LGPD e com o GDPR europeu.

Usuários entre 13 e 18 anos precisam do consentimento dos responsáveis, que podem solicitar a exclusão dos dados enviando email para privacy@folium.app.

## 11. Alterações nesta Política
Alterações relevantes serão comunicadas por email com **15 dias de antecedência**. Alterações menores (clareza de redação) não requerem notificação. A data de vigência sempre será atualizada no topo deste documento.
